# Simple C++ Chatbot

## Description

This is my first C++ chatbot project. It is a simple console-based chatbot that takes user input and responds to basic greetings and exit commands.

This project helped me practice basic C++ programming concepts such as:
- While loops
- If-else conditions
- String handling
- User input using getline()
- Basic control flow

## How to Run

### Compile

```bash
g++ TASK1.cpp -o chatbot
